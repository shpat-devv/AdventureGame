# AdventureGame

## Description

A simple Adventure game to learn c# basics where a user can find characters, add them to their account, then go on fights
to earn points.


## Functionality

Users can login or register accounts
Every user will have one base character
User can choose to go on fights or find more characters
Upon finding more characters, users can choose to add them to their account
When fighting, users can earn or lose points
